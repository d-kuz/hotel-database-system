#  Система управления хостелом
Реляционная база данных для управления гостиничным фондом хостела, включающая оперативную базу данных (OLTP) для ежедневных операций и хранилище данных (DWH) для исторического анализа. Система автоматизирует процессы заселения, выселения, учёта платежей и дополнительных услуг.

# О проекте
Система разработана с учётом специфики хостелов, где в одном номере могут проживать несколько человек, но с строгими правилами: совместное проживание разрешено только для людей одного пола или для семей, занимающих номер целиком.

# Ключевые возможности:
- Умное заселение: автоматическое определение «пола номера» (мужской/женский) при заселении первого жильца и проверка совместимости при добавлении новых.
- Динамическое ценообразование: автоматический расчёт стоимости проживания в зависимости от категории номера, его вместимости и количества ночей.
- История клиентов: централизованное хранение данных гостей. При повторном заселении данные не заполняются заново.
- Учёт дополнительных услуг: возможность добавления платных опций (кабельное ТВ, доставка еды и др.) с интеграцией в итоговый счёт при выселении.
- Автоматический перенос в DWH: при выселении данные об оплате и проживании автоматически архивируются в таблицы фактов хранилища данных для последующей аналитики.

# Архитектура системы

Система разделена на два логических уровня:

  [Оперативная БД (OLTP)](https://github.com/d-kuz/hotel-database-system/blob/d1c1bb7652538f62c952cc23ebf0930a3ad1c385/images/database.png):
  Оптимизирована для быстрых транзакций (заселение, выселение, оплата). Содержит нормализованные таблицы persons, rooms, categories, residents, pay_residents, pay_services.
 
 Структура базы данных:
 


  [Хранилище данных (DWH)](https://github.com/d-kuz/hotel-database-system/blob/d5e3bc095e125e76f04d71534c025af3331c598c/images/storage.png):
  Оптимизировано для аналитических запросов. Использует схему «звезда» с таблицей фактов h_fact_table и измерениями (h_person_dim, h_room_dim, h_time_dim). Данные переносятся сюда триггером/процедурой при выселении (check_out_person).
